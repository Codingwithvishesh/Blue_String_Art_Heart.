# 💙 Step-by-Step Electric Blue String Art Heart with Fine Sparkles

Aapke feedback ke anusar ye updates kiye gaye hain:

- **Electric Neon Blue Palette**: Saari lines aur glow pure electric cyan/blue me change kar di gayi hain.
- **Slow & Smooth Animation**: Speed ko slow kar diya gaya hai taaki heart aaram se step-by-step banta hua dikhe (32 seconds duration).
- **Fine Sparkles (Barik Embers)**: Heart ki line trace hote waqt active drawing point se barik glowing blue sparkles nikalte hain.
- **Controls**:
  - `R`: Animation ko reset / replay karne ke liye.
  - `ESC`: Window close karne ke liye.

---

## 🚀 Setup & Run

1. Dependencies install karein:
   ```bash
   pip install -r requirements.txt
   ```
2. Run karein:
   ```bash
   python main.py
   ```
